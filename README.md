## ⭐ Featured project

### [📅 Telegram Booking Bot](https://github.com/noname-programmer/telegram-booking-bot)

A universal booking bot for any business. Customers book in 4 taps, and the owner is notified instantly.

- One config file adapts it to a barbershop, a clinic, a car wash or a language school.
- Runs on Telegram Serverless (free hosting) or on any server with Docker.
- Protected against double bookings and forged buttons.
- Every change is checked automatically: linter, 28 scenarios × 5 configs, end-to-end test, Docker build.

**[▶️ Live demo: @schedule_mkapp](https://t.me/schedule_mkapp)** · **[Source code](https://github.com/noname-programmer/telegram-booking-bot)**
